# 대진GPI PVC 이음관 판매 홈페이지 시안

반응형 정적 웹사이트(HTML/CSS/JavaScript)입니다. 빌드 도구나 서버 없이 실행할 수 있습니다.

## 파일
- `index.html` : 메인 페이지와 제품 예시, 품질 안내, 견적 양식
- `styles.css` : 반응형 디자인
- `script.js` : 제품 필터/검색, 모바일 메뉴, 문의서 파일 저장

## 로컬 미리보기
`index.html` 파일을 브라우저에서 여세요.

## GitHub Pages 배포
1. GitHub에서 새 **Public** 저장소를 만듭니다(예: `pvc-fitting-store`).
2. 이 폴더의 파일 3개와 `README.md`를 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 설정하고 저장합니다.
5. 배포 완료 후 Pages 화면에 표시되는 URL로 접속합니다.

## 운영 전 반드시 확인할 사항
- 제품명·호칭·각도·판매 규격을 실제 제품 마스터와 대조
- 실제 도면, 두께 측정 기준, 시험성적서, 적용 규격 확인
- 전화번호, 이메일, 사업자 정보, 주소 입력
- 개인정보 처리방침 및 문의 개인정보 처리 방식 마련
- 현재 문의 양식은 브라우저에서 TXT 파일을 생성할 뿐, 서버 저장·메일 발송·주문/결제 기능은 없습니다.
- 가격, 재고, 배송비, 거래처별 단가 및 결제 기능은 별도 구현이 필요합니다.
- 제품 일러스트는 시안용 벡터 그래픽이며 실제 제품 사진이 아닙니다.
- 두께/내구성 비교 문구는 객관적인 비교 자료가 확인된 뒤 게시하세요.

## 기술
순수 HTML, CSS, JavaScript. 외부 라이브러리 불필요. Google Fonts 연결은 인터넷이 필요합니다.
